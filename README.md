# Girls United Vietnam — Website

A responsive, multi-page static website built with HTML, CSS and JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About us
- `initiatives.html` — Our initiatives
- `events.html` — Events
- `get-involved.html` — Get involved

## Preview locally
1. Download and unzip the project.
2. Open `index.html` in a browser.
3. For a more reliable local preview, use the VS Code extension **Live Server** and select "Open with Live Server".

## Publish with GitHub Pages
1. Create a new **public** GitHub repository, for example `girls-united-vietnam`.
2. Upload the contents of this folder (not the outer folder itself) to the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. GitHub will provide a public URL after deployment finishes.

## Before publishing — important checklist
- Replace the typographic `GUV` placeholder with the official Girls United Vietnam logo if desired.
- Review and approve all mission and programme wording.
- Replace stock photography with photos you have permission to use, ideally authentic programme and community photos with informed consent.
- Add official contact email and social media links.
- Connect the enquiry form in `get-involved.html` to Google Forms, Formspree or another form provider. The current form is only a front-end preview and does not send submissions.
- Add real event dates, registration links and impact figures only after they are confirmed.
- Review safeguarding, privacy and photo-consent practices before collecting information from young people.

## Customising the site
- Colours and responsive layouts: `assets/css/styles.css`
- Mobile menu and form preview: `assets/js/main.js`
- Page content: the relevant `.html` file

## Images and fonts
The current design uses remotely hosted Unsplash images and Google Fonts. An internet connection is required for those assets to load. Replace them with locally stored, properly licensed images before long-term use if preferred.
